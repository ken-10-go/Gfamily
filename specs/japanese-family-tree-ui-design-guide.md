# UI/UX デザインガイドライン及び表示仕様書 (UI/UX Design Guide v1)

本ドキュメントは、AIコーディングエージェント（Claude Code等）に読み込ませ、Flutter等のマルチプラットフォーム環境において、高い操作性と日本の文化的背景に寄り添った家系図表示・編集UIを自律開発させるための「デザイン仕様・実装インプット」である。

---

## 1. 全体デザイン・テーマシステム (Themes & Visual Styles)

アプリ全体のトーン＆マナーは、日本の伝統的な家族史を記録するという性質に合わせ、信頼感と落ち着きのある「和風モダン」をベースとし、ユーザーが好みに応じてパーソナライズできるテーマ選択仕様とする。

### 1.1 カラーパレット & デザインプリセット
ユーザーは家系図全体のデザインテーマ（スキン）を動的に切り替え可能とする。

| テーマ名 | 役割・イメージ | 主要カラー構成 |
| :--- | :--- | :--- |
| **和風モダン (デフォルト)** | 折本や屏風、和装本を想起させる信頼感のあるテーマ | 背景：生成り色 (`#FAF9F6`), カード：漆黒/藍鼠 (`#2C3E50`), 枠線：金煤竹 (`#C5A059`) |
| **モノトーン (Monotone)** | 相続手続きや法定相続情報など、実務的・公的な用途向け | 背景：純白 (`#FFFFFF`), カード：グレースケール (`#333333`, `#F5F5F5`), 枠線：ダークグレー |
| **パステル・ベビー** | 子どもの成長記録や若年層向けの明るいテーマ | 背景：ソフトホワイト, カード：薄桜 (`#FFD1DC`) / 浅葱 (`#83CCD2`) 等、優しいパステルカラー |

### 1.2 状態表現ルール
*   **故人カード表示 (Deceased Status)**: 
    *   故人（`isDeceased = true`）のカードは、一目で区別できるよう**「グレー背景」**、または**「モノトーン調」**に自動減色して描画する。
    *   生存者カードとコントラストをつけることで、系図全体の視認性を大幅に向上させる。
*   **メインパスの強調表示 (Path Highlight)**:
    *   選択した人物から直系の祖先、または「自分」から対象の先祖までの系譜線を太いゴールド（またはテーマのプライマリカラー）で強調表示する。

## 2. 人物カード（ノード）の動的表示仕様 (Dynamic Person Cards)

家系図の各人物を表すカード（ノード）は、表示する情報量や用途に応じて動的にカスタマイズできる「カード表示項目カスタマイズ機能」を実装する。

### 2.1 カードのサイズと自動調整
*   **基本カードサイズ**: 幅 250dp、高さ 70dp〜（自動高さ調整対応）。
*   **カードサイズ自動調整 (Auto-height)**:
    *   ユーザーがカード内に表示する情報項目を追加・削減した際、カードの幅は固定し、高さがテキスト量に応じて動的に伸縮する。

### 2.2 カード表示項目の設定マトリクス (1〜6行の動的割当)
設定画面から、カード内に表示するテキストの行数（1行〜最大6行）と、各行に割り当てるデータベース属性をユーザーが自由にマッピングできる仕様とする。

```
【カード表示項目の割り当て例 (実務・相続向け設定)】
┌──────────────────────────────────────────────┐
│ [M] 山田 太郎 (72)       [直系パス強調線]  │ <- 1行目: 性、名、(年齢 / 故人時は享年)
│ 出生: 昭和44年12月31日                       │ <- 2行目: 出生日 (和暦・西暦自動変換)
│ 死亡: 令和11年12月31日                       │ <- 3行目: 死亡日 (和暦・西暦自動変換)
│ 本籍: 東京都千代田区永田町1-7-1               │ <- 4行目: 本籍地 (非暗号化/プレーンテキスト部分)
│ 住所: 東京都千代田区永田町1-7-2               │ <- 5行目: 住所 (存命時はE2EE復号データ)
│ 続柄: 被相続人 (長男)                         │ <- 6行目: 続柄・親等 / 法定相続分
└──────────────────────────────────────────────┘
```

*   **選択可能な項目リスト**:
    *   姓、名、よみ、出生日（和暦/西暦）、死亡日（和暦/西暦）、続柄、親等数、住所、本籍地、法定相続分、戒名・法名、家紋アイコン。

## 3. 日本独自の「ビジュアル代替仕様」 (Japanese Visual Fallbacks)

日本の古い戸籍や過去帳を遡ると、明治期以前の先祖については「名前以外の記録がなく、写真（肖像画）が絶対に手に入らない」ケースが多発する。文字だけの味気ない家系図になるのを防ぐため、以下のビジュアル代替機能を実装する。

### 3.1 写真なしノードのスマートフォールバック (Photo Fallback UI)
人物に個人の顔写真が登録されていない場合、以下の優先順位で「関連ビジュアル」をカードや詳細ダイアログに自動描画する。

1.  **ゆかりの地・建物の写真**:
    *   先祖の本籍地、旧実家、本家、ゆかりの寺院や墓地、歴史的建造物の写真を登録・表示可能とする。
2.  **名字の由来・歴史グラフィック**:
    *   登録された「名字（姓）」に基づき、名字由来データベースから得られたルーツ（例：「山田」＝田んぼ・山間の風景をモチーフにした和風イラスト）をプレースホルダーとして自動生成・描画する。
3.  **家紋グラフィック**:
    *   ツリーまたは個人に紐付けられた家紋グラフィック（8,000種以上の家紋マスターから選択したもの）を、中央プレースホルダーとして美しく配置する。

## 4. インタラクティブなツリー操作・ナビゲーション (Interactive Navigation)

スマートフォンの限られた画面幅（物理的制約）で、高祖父母（4代前）や昆孫（8代後）に及ぶ100人以上の大規模な家系図を破綻なく表示するためのダイナミックなUI操作を定義する。

### 4.1 選択人物・フォーカス中央表示 (Dynamic Center Focus)
*   **挙動**:
    *   任意の人物カードをタップ（またはダブルタップ）した際、その人物を画面の「中央（中心）」にアニメーションでスムーズに移動（遷移時間: 1000ms）させる。
*   **視野深度の動的制限（ズーム＆デプス制御）**:
    *   フォーカスされた人物を中心に、画面に描画する「祖先の深さ（Ancestor Depth）」と「子孫の深さ（Descendant Depth）」を、設定されたスライダー（デフォルト：各3代、最大5代）に基づいて動的にフィルタリングする。これにより、描画ノード数を制限し、パフォーマンスと視認性を極限まで高める。

### 4.2 直感的なドラッグ＆ドロップによる兄弟姉妹の並び替え (Sibling Reordering)
*   日本の家系図において、長男、次男、長女などの誕生順（左から右、または右から左）は極めて重要である。
*   **UI仕様**:
    *   家系図編集モードにおいて、同一親から生まれた兄弟姉妹のノードを「長押し（Long Press）」することで並び替えモードに移行する。
    *   ドラッグ＆ドロップで左右の順序を入れ替えると、背後のデータ構造（`sortOrder` 値）がリアルタイムに更新され、リレーションシップ線が交差することなく自動的に再描画される。

### 4.3 縦書き（伝統）と横書き（現代）のダイナミックレイアウト切り替え
*   **縦書きモード (Vertical Calligraphy View)**:
    *   日本の伝統的な毛筆・折本形式に則り、画面の「右から左」へ時間が流れ（右が先祖・長男、左が子孫・末子）、「上から下」に親子関係の系譜線を引く。テキストは縦書きで配置。
*   **横書きモード (Horizontal Layout View)**:
    *   現代の画面に最適化された、上が先祖、下が子孫、または左が先祖、右が子孫へと展開する、フローチャート組織図に近い表示（水平方向のレイアウト）。
*   **共通パラメータ仕様**:
    *   `カード間隔（縦方向）`: デフォルト 200dp
    *   `カード間隔（横方向）`: デフォルト 350dp
    *   `空の配偶者カードの表示`: 独身または配偶者データが未登録の場合、「空の配偶者カード（表示文字：配偶者 / ＋をタップで新規追加）」をプレースホルダーとして描画し、入力の導線を確保する。

## 5. 日本の暦と年中行事の統合年表UI (Memorial & Event Timeline UI)

各人物のプロファイル画面では、西暦と元号がシームレスに調和し、日本の伝統的な暦（ライフイベント・供養イベント）を網羅するタイムラインを美しく表示する。

### 5.1 暦・ライフイベント自動マッピング
生年月日および没年月日を基準として、以下のイベントを日付軸の年表に自動的にプロットし、ビジュアルバッジを付与する。

*   **長寿の祝い**: 還暦（60歳）、古希（70歳）、喜寿（77歳）、傘寿（80歳）、米寿（88歳）、卒寿（90歳）、白寿（99歳）、百寿（100歳）の年に「桜色」の長寿お祝いバッジを表示。
*   **伝統的イベント**: 七五三、成人式、厄年（前厄・本厄・後厄）、干支（年男・年女）。
*   **仏教供養イベント**:
    *   故人の命日（祥月命日）年表。
    *   回忌法要（一周忌、三回忌、七回忌、十三回忌、十七回忌、二十三回忌、二十七回忌、三十三回忌）の該当年を自動算出し、「蓮の花」をモチーフにした法要予定バッジを表示。
