# 使い方ガイドのもと（Claude へのインプット）

このファイルは、**家系図G の使い方ガイドを Claude のチャットで書いてもらうための材料**です。
そのまま貼り付けて使えます。前半が依頼文、後半が事実の材料です。

## 依頼文（ここから貼る）

以下の材料をもとに、家族向けの「使い方ガイド」を日本語で書いてください。

**読み手**: 60〜80代を含む親戚。家系図アプリを使うのは初めてで、多くはスマートフォンで見ます。
パソコンやアプリの用語には慣れていません。

**目的**: 「押しても動かない」「勝手に配置が変わった」と困る前に、
このアプリ独自の考え方（段・配置・家）を先に分かってもらうこと。

**書き方の約束**:

- 見出しごとに、短い説明の段落を1つと、箇条書きを数行。1つの見出しが**スマホの1画面**に収まる長さ。
- 「何ができるか → どう操作するか → なぜそうなっているか」の順。**理由まで書く**
  （理由が分かれば操作を覚えなくて済むため）。
- 操作の名前は、材料に書いてある**アプリの文言のまま**使う（「段を数字で指定する…」など。
  言い換えない）。
- 専門用語（ノード、レイアウト、キャッシュ、レンダリング等）は使わない。
- 手順は「〜を押します」「〜が出ます」の丁寧語。命令形にしない。
- 見出しは `##` から始める。`#` は使わない。
- 全体で 2,000〜3,000 字くらい。最後に「困ったときの見分け方」を Q&A で置く。

**入れないでほしいもの**: 見れば分かること（人物の追加ボタン、検索、画面下のタブの移動、
ログインの仕方）。細かい仕様の羅列。

## 材料（アプリの事実。ここから下は実装から起こしたもの）

### 0. アプリの全体像

- 名前は「家系図G」。家族・親戚だけで共有する家系図。招待されないと入れない。
- 画面の下に5つのタブ: **ホーム／家族／＋／家系図／設定**。行き先はここに集めてある。
- 「家系図」が図の画面。ここでカードを触って操作する。

### 1. 段（世代）— このアプリでいちばん独特なところ

**自動で決まる。** 段は次の3つの決まりから自動で計算される。

1. 子は親より1つ下の段
2. 夫婦は同じ段
3. 親は、いちばん上の子のすぐ上の段まで下りてくる

3 があるのは、婚姻で子が下へ引かれたときに親だけが上に取り残されるのを防ぐため。

**手でも動かせる**（編集できる人のみ）。カードを1回タップ →「⋯ その他」の中に:

- 「1つ上の段へ」／「1つ下の段へ」
- 「段を数字で指定する…」— 図の左に出る段の番号（設定の「段の番号を図の左に出す」で表示）
  と同じ数字を入れると、その段へ移る
- 「段を自動に戻す」— 手で動かした人にだけ出る

**保存されるのは「絶対の段」ではなく「ずれ（差）」。** あとから人物を足して自動側の段が
変わっても、手で入れた指定の意味が保たれるため。

**動かないことがある。** 親が子と同じ段か、子より下に来てしまう指定は、無効になって
元へ戻される。上下が入れ替わると親子の線が逆向きになり、図として読めなくなるため。
このとき**誰が引っかかっているかを名前で知らせる**（黙って消えると「押しても動かない」に見えるため）。
配偶者は同じ段に付いて動くので、**配偶者側の親子関係**が原因のこともある。

### 2. 配置（自動と手動）

- 図は既定で**自動配置**。家ごとにまとまり、夫婦は隣、親は子の上に来るよう自動で置かれる。
- **手で動かせるのは左右だけ。上下は必ず段で決まる。** 縦まで自由にすると、
  カードの大きさや表示項目を変えたときに、保存した位置が古いままずれてしまうため。
- 指で動かすときは**長押し（約0.4秒）してから**ドラッグ。なぞっただけで動くと、
  意図しない位置が保存されて「勝手に固定された」ように見えるため。
- 手で置いた親の下にいる子は、**親についてまとまって動く**（ぶつかる手前で止まる）。
- 戻したいとき: そのカードのメニューの「自動配置に戻す」（手で置いた人にだけ出る）、
  または右上の「⋯」→「全体を自動配置に戻す」。

### 3. 家（◯◯家）

- **家 = 婚姻の線を外し、家を継ぐ側の親だけをたどってつながる一群**。
  婚姻は家と家を「つなぐ」ものなので、たどる対象から外すと家の輪郭が出る。
- **既定は自動判定。何も登録しなくても成り立つ**（いちばん多い姓から「◯◯家」と名前が付く）。
- **1人が複数の家に属してよい**（生家と婚家、実家と養家）。
  **先頭が「主たる家」**で、図のまとまりに使うのはこれだけ。残りは所属の記録。
- 付け外しできる場所は2つ: 人物の編集画面の**「文化的補足」タブ**と、
  設定 →**「家の管理」**（オーナーのみ）。
- 自動判定に出てこない家（同じ姓の別の家など）は、**名前だけ決めて足せる**（「家を追加」）。
- **家は1枚に畳める**: カードのメニュー →「この家を1枚に畳む」。
  「◯◯家（n人）」の1枚になり、家の外へのつながりだけが残る。
  開くのは、その畳んだカードを叩くか、右上の「⋯」→「畳んだ家をすべて開く」。
  **畳んだ状態はこの端末の見た目だけ**で、データは何も変わらない。他の家族の画面にも影響しない。

### 4. カードの3つの操作

- **1回タップ = メニュー。** よく使う5つ（編集・親を追加・配偶者を追加・子を追加・削除）が
  カードのまわりに弧の形で出て、「⋯ その他」から残りが開く。
  画面が狭いときは、弧をやめて**画面下から大きなボタンのシート**が出る。
- **ダブルタップ = その人を中心に絞り込む。** まわりだけが残り、画面の中央に寄る。
  もう一度ダブルタップで全体に戻る。
- **長押ししてドラッグ = きょうだいの並べ替え。** きょうだいの列の中で離すと並び順が変わり、
  列から大きく外して離すと左右の位置の指定になる。
  戻すときはメニューの「並び順を生年順に戻す」（その列の全員が対象）。

そのほかメニューにあるもの: 「詳細を見る」「両親をまとめて追加」「既存の人物を親／配偶者／子にする」
「画面の中央に寄せる」「この人を中心に絞り込む」。

### 5. 絞り込みと、血縁の色づけ

- 絞り込み中は**自動配置で描く**（手で置いた位置は全体を前提にした値なので、
  一部だけを取り出すと取り残されるため）。絞り込みを解けば元の配置に戻る。
- 絞り込みのいちばん外側の人は**薄く表示**される。「ここで切れているが、その先も家系は続く」の印。
- カードを選ぶと、その人の**直系の親・きょうだい・子孫**がカードも線も色づく
  （設定の「選んだ人の血縁（親・きょうだい・子孫）を強調」）。

### 6. 見た目の設定（右上の「⋯」→「表示設定」）

- **縦書き／横書きの切り替え**（ヘッダーの「縦」「横」ボタンでも切り替わる）。
  縦書きでは生没年のあいだの横棒が縦の棒になる。
- カードに出す項目（ふりがな・生没年・続柄など）、年齢を氏名の横に出すか、
  段の番号を図の左に出すか、丸アバターを添えるか、配偶者の空カードを出すか。
- 「編集を止める（誤操作の防止）」— 見るだけにしたいときに使う。
- 拡大縮小: マウスのホイール、**指2本のピンチ**、画面右下の「＋／−／全体」。
- **表示設定はその端末だけのもの。** 他の家族の画面は変わらない。
  みんなに影響するのは、人物の内容と関係（親子・夫婦）を編集したときだけ。

### 7. 消す・戻す

- 人を消しても、すぐには消えない（**ゴミ箱**に残り、戻せる）。
- ゴミ箱から**完全に削除**できるのはオーナーだけ。完全に削除すると、その人につながる関係も消える。

### 8. 権限（人によって画面が違う理由）

- **閲覧者**: 見るだけ。カードのメニューにも編集の項目は出ない。
- **編集者**: 人物と関係を足したり直したりできる。
- **オーナー**: 上に加えて、メンバーの管理・招待・家の管理・家どうしのつながり・
  取り込み・ゴミ箱の完全削除ができる。
- 設定の画面に出る項目が人によって違うのはこのため（押しても断られる行き先を並べないようにしている）。

### 9. ほかの道具からの取り込み（オーナーのみ）

- 「すいすい家系図」の書き出しファイル（`.ftz` / `node.ftt`）を読み込める。設定 →「家系図を取り込む」。
- 既にいる人との重なりは**氏名だけで突き合わせる**（生年で照合すると、
  片方にだけ日付が入っている同じ人を別人にしてしまうため）。取り込む前に、足される人の一覧を確認できる。

### 10. アプリとして使う・更新

- 設定の「ホーム画面に追加」でアプリのように開ける（iPhone はブラウザの共有メニューから）。
- 新しい版が出ると画面の上に帯が出る。設定の「アプリの更新」からも読み込み直せる。
- 右上に版が出る（例: ver.1.95）。不具合を知らせるときに添えると助かる。

### 11. 実際に出た「困った」と、その見分け方（Q&A の材料）

- **段を上げ下げしても動かない** → 親子の上下が入れ替わる指定は無効になっている。
  知らせに出た名前の人を先に動かす。配偶者の側の親子関係が原因のこともある。
- **配置が勝手に変わった気がする** → 手で置いた親を動かすと、下の子はついて動く仕様。
  戻すなら「⋯ → 全体を自動配置に戻す」。
- **カードが勝手に固定された** → 指のタップが長押しドラッグと判定された可能性。
  そのカードのメニューの「自動配置に戻す」で戻せる。
- **同じ「◯◯家」が2つ出る** → 同じ姓でも血のつながりが分かれていると別の一群として見える。
  名前を付けて登録すれば1つにまとまる。
- **家を畳んだら線が変** → 畳んだ家に対して「親でもあり配偶者でもある」関係ができるため、
  親としての線は畳んだ中に吸収して表示から落としている。開けば元通り。
- **年齢が実際と1つ違う** → 年齢は学年と同じ数え方（その年に何歳になるか）で出している。
